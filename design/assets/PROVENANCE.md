# 示例素材来源

`outfit-sprites-original.png` 为本次通过内置 image generation 工具生成的 1024×1536 透明背景拼图，包含六位虚构成年女性的穿搭示例；`outfit-sprites.webp` 为保留透明通道的缩小压缩版本，供网页原型使用。

生成意图：六个互不重叠的全身人物，三列两行；粉色衬衫与牛仔裤、黑色上衣与牛仔裤、米色风衣与深色裤、彩色条纹针织衫与牛仔裤、白衬衫与灰裙、黑色套装；自然摄影质感，白色贴纸边缘，背景透明，不含文字、品牌或水印。

这些素材只展示 UI 视觉，不是 Vision 真机抠图结果，也不代表真实用户、代言或用户授权肖像。正式 App 不预装这组六个人物作为用户记录。不得把原型中的素材处理效果宣传为产品实测效果。

用户提供的小红书截图仅作为设计参考，未复制到本仓库。未来添加第三方照片时必须另记来源和授权；代码的 MIT 许可不自动覆盖新增第三方素材或人格权。
