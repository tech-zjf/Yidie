# 验证清单

本文件区分交付包检查与未来 App 验收。UI 原型能切换和点击，不代表 Apple Vision、PhotoKit 或备份恢复已经工作。原生项目创建后，应填写设备型号、系统、构建号和实际结果。

## 本次交付包检查

- 检查相对文档链接、SQL 建表和关键约束、原型 JS 语法。
- 在浏览器检查月历、当天展开、批量导入及其他页面；测试窄屏和无横向溢出。
- 使用生成的示例照片，未导入任何用户私人穿搭照片。
- 本次未安装 Expo 工程、未编译 Swift、未做 iPhone 真机测试、未创建公开仓库。

实际执行摘要见 [CHECKS.md](../CHECKS.md)。

## 记录格式

每次测试填写：构建号、设备/系统、样本编号、操作、预期、实际、耗时/内存（需要时）、通过或失败、关联修复。样本照片只保存在自有测试设备；公开 issue 仅包含用户同意分享的素材。

首版不存在统计 SDK，因此产品反馈通过主动访谈、构建反馈和自愿 issue 收集。测试者不能成功安装，应单独记为分发问题，不能直接视为不喜欢产品。
