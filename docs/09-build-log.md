## Reproduce local checks

From `apps/mobile`:

```sh
npm ci

npm run export:ios
```

```sh
sh scripts/check_native.sh
python3 scripts/check_packet.py
```

For the complete unsigned Xcode Simulator build procedure and signing boundaries, see the [mobile build guide](../apps/mobile/README.md). For general device-testing boundaries, see the [local device testing and safety guide](15-device-test-safety-runbook.md). Keep personal device-state and rollback notes outside the repository.
