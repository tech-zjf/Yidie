# UI 与交互规范

视觉参考用户提供的日历贴纸截图：白色背景、黑色大字、无格线日历、真实照片抠出的白边贴纸，以及一个蓝色添加按钮。保留安静、轻盈的页面，不增加仪表盘、积分和装饰卡片。

## 设计交付

[交互原型](../design/index.html) 包含 11 个入口；[总览](../design/overview.html) 并排展示 9 个主要页面。原型仅用于浏览和状态演示，所有照片是示例，月份固定为 2026 年 6 月，满月展示 2026 年 7 月。正式 App 使用当前月份。顶部的页面选择器不是 App 功能。

阶段 4 的 RN 开发入口为：本地相册多选 → 原照片按日期分组确认 → 已加入队列；组/单张日期编辑在同一弹层内切换，不叠加 Modal。月历下方及提交结果页显示等待、暂停和失败数量，支持暂停/继续；全部处理成功后月历队列提示隐藏。主动暂停需点击继续，失败项从记录页单独重试。当前每批上限 10 张。该入口已实现代码，尚未完成真机小屏、键盘和大字体视觉验收；网页生成中动画不代表 RN 已实现。

网页不是最终 RN 组件，也不接入真实照片权限、模型、文件或原生分享。日期编辑、备份和导出的终态以本文与 PRD 为准，原型用提示模拟。系统照片选择器、系统分享与文件选择面板沿用 iOS，不另外重画成自定义系统界面。

## 页面说明

月份的微倾斜衬线与有起伏的数字营造纸质日历感；日历字体保持不变。Bagel Fat One 用于短标题和展示文案，英文正文使用 Avenir Next 保持清楚轻盈，避免长段文字都使用展示字体。字体源文件与 OFL 许可证见 [字体说明](../design/assets/fonts/README.md)。字体随 App 本地打包，不依赖运行时网络请求。

## 堆叠与日期

建议 3 层使用约 -11° / -4° / 9°，水平错位收紧到 4pt 左右，让前景照片占主要面积、后层只露少量轮廓。正式实现以 alpha 边界和真机观感调整。用户提出的 10° / 30° / 60° 会在一周七列里占用过多横向空间，适合单日大图玩法，暂不作为月历默认。

有记录时，贴纸直接占据日期位置，不显示该格日期数字。同一天多张时在贴纸堆右上角显示小圆数量标记，单张不显示角标。没有记录的格子才显示居中的日期。贴纸允许在格子周围轻微溢出，但不能挡住相邻空格的数字或星期标题。最多显示 3 张，点击后再显示准确日期与总张数；可访问名称始终为“6月12日，4张穿搭”。

贴纸有透明 padding 时先按主体边界归一化，不能仅看 PNG 的矩形宽高。人物展示优先于数字；全身与半身可自然混排，不强行在人物脚下保留一行日期。原型的半身示例通过展示裁切说明视觉方向；正式 App 默认保留用户照片中的完整主体，裁切需由用户选择。

跨日期的贴纸不得相碰。同一天的旋转、位移与白边合并成一组后，先计算整组的可见轮廓包围盒，再整体等比缩放、居中，不能只限制单张图片的高度。设计以整组轮廓加阴影余量为准，垂直预留至少 14pt 的日期间空隙，水平至少 6pt。当前 390pt 宽原型的普通月历行高为 82pt，窄屏为 78pt；六周月份自动使用更紧凑行高，并相应收小贴纸组。原型用示例图片的 alpha 边界做近似，正式 App 应使用处理后每张图片的真实边界。

默认封面为排序首张，也可明确指定。变化仅影响最上层，所有记录在横向列表中仍可访问。保存稳定角度和顺序，动画中也不能重新随机。31 天密集样本与 6 周样本都应单独验证；原型默认满月页展示 7 月，加上 `?six-weeks=1#dense` 可查看 2026 年 8 月六周密集样本。

## 底部弹层

默认展开到约屏幕 70%，照片区横向分页，下一张露出 16–24pt。日期详情层以遮罩淡入、面板轻移入场，关闭时反向过渡；导入与全部记录沿用 iOS 原生 page sheet 过渡。照片、状态说明、编辑操作和页码在同一张卡片宽度内居中对齐。顶部明确日期、张数和添加入口；主要操作为设封面和编辑，分享与删除使用次级操作。只对当前可见项执行操作，滑动结束后更新选中 id，不能依赖数组旧索引。失败状态展示对应错误说明，不只展示通用失败文案。

正式 App 打开弹层时将 VoiceOver 焦点移入，关闭后回到原日期；遮罩后的月历不再接收键盘和读屏操作。这里是实现验收要求，网页演示未完整模拟原生无障碍焦点管理。

## 导入与错误文案

- 无日期：“这两张，拍在哪一天？”动作“选择记录日期”或“暂存待归档”。
- 抠图失败：“这张暂时没剪好。”动作“重新生成贴纸”或“保留照片样式”。
- iCloud 资源未下载：“照片还没下载到手机。”让用户先在系统相册下载，回到衣叠重试。
- 空间不足：“手机空间不够了。已保留完成的 8 张。”不把成功部分撤回。
- 照片权限：“选几张照片就好。”按需选择有限照片，不把拒绝权限显示为系统错误。
- 删除记录：“只删除衣叠内的记录，系统相册里的照片会保留。”
- 清空：“删除后无法撤销。建议先导出完整备份。”

## 屏幕之外

App 图标采用暖白底、错开的相片纸页和剪影人物；可编辑 SVG 源稿保存在 `design/assets/brand/`，iOS 使用 1024px PNG。首页左上保留品牌标记与 Yidie 字标，About 在右侧；页脚只保留居中的 All records 与添加按钮。月历支持左右滑动换月，首页隐藏滚动条并优先在一屏内显示。分享海报优先突出用户照片，品牌署名默认关闭。
