# 命名

建议采用 **衣叠**，英文工程名 **Yidie**，读作“yī dié”。“衣”说明穿搭，“叠”对应同日多张贴纸，也自然联想到“一叠照片”。两字短、容易说、容易记，能直接解释核心交互。

| 候选 | 好处 | 顾虑 | 结论 |
| --- | --- | --- | --- |
| 衣叠 | 与衣服、照片、堆叠直接关联；有“一叠”的口语联想 | 拼音不是英语单词；首次对外要解释读音 | 采用 |
| 衣页 | 轻、短，像翻过一页穿搭 | “页”更像阅读，不能直接表达叠放 | 备选 |
| 叠日 | 体现日期与收藏 | 口头表达稍生硬，不直接联想到穿搭 | 不优先 |
| 衣记 | 一眼能理解记录穿搭 | 通用且容易与既有衣物记录产品相混 | 不采用 |
| 穿日记 | 容易理解使用场景 | 三字，读起来不够自然 | 不采用 |

中文名称用于 App、标题、截图；Yidie 用于目录、仓库候选名和英文 README。建议 tagline 为“把穿过的日子，一张张叠起来。”英文说明为“Your outfits, stacked into days.”

初步网页检索没有建立名称、商标、域名或 GitHub handle 的排他性。当前只是项目工作名；公开发布前再次搜索中文 App Store、GitHub、常用搜索引擎，并按实际需要做商标查询。不得把本地目录创建成功当成名字已被注册或全球唯一。

Bundle identifier 由开发者自己的反向域名空间确定，例如 `com.<owner>.yidie` 是结构说明，不能直接作为最终配置。当前没有购买域名、注册品牌、创建外部账号或远程仓库。
