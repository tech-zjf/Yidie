# Changelog

Notable user-facing changes are recorded here. Unreleased development work remains in Git history; this file is updated when a change is ready to describe to users.

## [Unreleased]

### Added

- Calendar-first outfit diary with batch photo selection, date confirmation, same-day sticker stacks, and horizontal day browsing.
- On-device subject extraction and editable local sticker treatments: Original, Outline, Comic, 3D, and Shimmer.
- Local `.yidie` backup and restore for the app's records and image assets.

### Privacy

- Selected photos, records, cutouts, and sticker rendering stay on the device. The app has no account, backend, analytics, or cloud image processing.

### Known limitations

- Sticker treatments are independent local effects, not 1:1 copies of Apple Photos effects. Interactive Simulator and real-photo device acceptance are still in progress.
