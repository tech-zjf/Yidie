# Security policy

Yidie is an early-stage local-first app. Backup and restore are implemented, but `.yidie` packages are not encrypted and must be saved to a location you control and verified before relying on them. Keep an independent copy of important photos; uninstalling Yidie can remove its local records and imported copies.

Do not report a suspected vulnerability with private photos, app databases, device identifiers, credentials, signing certificates, or provisioning profiles attached.

If GitHub private vulnerability reporting is enabled for this repository, use **Security → Report a vulnerability**. Otherwise, contact the repository owner through the contact method on the GitHub profile and include only a concise description and safe reproduction steps. Do not publish exploit details in a public issue before a fix is available.

There is no guaranteed response or patch timeline while the project is maintained as a personal open-source project.
